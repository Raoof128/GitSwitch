# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, professional, and harassment-free experience for everyone participating in the GitSwitch project and community --- regardless of background, identity, or experience level.

A healthy contributor community is essential to building security-first software. Trust in the project starts with trust between the people who build it.

## Expected Behavior

- Be respectful, constructive, and collaborative in all interactions.
- Focus feedback on the work, not the person. Critique code and ideas, not contributors.
- Assume good intent while maintaining technical rigor.
- Help keep discussions accessible to contributors with different backgrounds and experience levels.
- Follow the project's [contributing guidelines](CONTRIBUTING.md) and [security policy](SECURITY.md).

## Unacceptable Behavior

- Harassment, intimidation, or discrimination of any kind
- Personal attacks, trolling, or sustained hostility
- Sharing private information (including security vulnerabilities) without permission
- Sexualized language or imagery in project spaces
- Disruptive behavior that undermines productive collaboration
- Deliberately introducing malicious code or security vulnerabilities

## Scope

This Code of Conduct applies to all project spaces --- including GitHub issues, pull requests, discussions, commit messages, and any communication channels associated with GitSwitch. It also applies when an individual is representing the project in public spaces.

## Enforcement

Project maintainers are responsible for upholding this Code of Conduct. They may remove, edit, or reject comments, commits, code, issues, and other contributions that violate these standards. Enforcement actions will be proportional to the severity of the violation.

## Reporting

To report unacceptable behavior, contact [raoof.r12@gmail.com](mailto:raoof.r12@gmail.com). All reports will be reviewed promptly and handled with confidentiality. The reporter's identity will not be disclosed without their consent.
